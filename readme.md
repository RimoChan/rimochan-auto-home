# 莉沫酱家里！

大家有用过智能家居吗？

前1段时间我也买了1套智能家居，空调、灯、插线板、窗帘之类的，什么都有。

结果买回来之后，发现这些「智能」产品大多不是很智能，没有蟾蜍先生的1半聪明！

于是我就在家部署了home assistant服务，它可以控制智能家居，相当于是家的管理中心，我可以在上面配置自动化，让智能家居变得聪明1些。

所以这个仓库就是放我在home assistant上写的自动化文件，这样大家以后买了智能家居，可以把它们抄回去，就不会觉得智能家居那么难用了！


## 使用方法

在home assistant的「自动化与场景」页面创建1个新的自动化，然后在右上角进入「以YAML编辑」，把你想要的yaml粘贴进去就可以了。

不过仓库里的配置文件中device_id字段被替换成了占位符，你要记得把它们改成你的device_id！


## 介绍1些自动化

**究极太阳常亮**:
- 这个是控制房间亮度的程序。
- 之前听说现代人因为生物钟混乱，导致了失眠这样的问题。于是我就想，那不如用智能灯泡来模拟太阳在1日间的变化，这样不就能修好生物钟了吗！所以就用这个代码，让它根据时间调整亮度和色温，比如在中午更亮1些，在晚上则逐渐变暗，来帮助我睡眠！
- 此外还写了客厅和厕所的版本，数值有点差异不过机制是1样的，就不介绍了！

**初升的东曦**:
- 这个是光学闹钟程序。
- 它会在快到早上10点的时候把床头灯的亮度从0逐渐提升到100，模拟太阳升起来把人叫醒的感觉，这样就不会被闹钟吓到了。此外，因为闹钟是广播1个变化，不是广播1个状态，用闹钟的时候经常早上醒来很害怕，担心自己是不是睡过头错过了闹钟，不得不手动看1下时间。用初升的东曦就没有这个问题，只要房间是暗的就说明还能睡！

**异热同心**:
- 这个是设定空调温度控制的程序。
- 现在有很多所谓的「智能」空调，所谓的功能1大堆，结果连空调温度不精确的问题都没有解决，真是让人笑掉大牙！不过好在空调温度可以通过API调整，那就自己写1个吧。基本原理就是新增1个设定目标温度的控件，先用房间中央的树莓派传感器测出真实温度，然后根据真实温度和目标温度计算出1个假的目标温度发给空调进行反向补偿。

**奇迹之风**:
- 这个是根据空调温差自动调风速的程序。
- 和上1个很像，空调的调风速逻辑也很奇怪。制冷模式下，我已经把目标温度调得比真实温度还高了，结果它还在那边疯狂吹风，是想把我吵死！所以也就不开自动风速了，自己写1个根据温差控制风速！

**魔雾雨**:
- 这个是控制加湿器的程序。
- 除了空调以外，还有很多自称智能的设备也有类似的问题。比如智能加湿器，所谓智能主要就是可以根据环境湿度自动调整档位，但实际上它们的传感器是在机器身上的，然后它自己喷自己，测出的环境湿度值根本不准。所以用这个程序来轮询房间里的湿度计的湿度，决定是否调整档位，这样1来房间就可以真正地恒定湿度了！

**炼狱的泛烂**:
- 这个是睡觉时的空调与加热器的平滑补偿程序。
- 人在睡觉时随着后半夜体温下降，很容易在清晨被冻醒。这个程序会在凌晨1点多到早上6点多之间，把房间的目标温度平缓线性提升几度，营造最舒服的睡眠环境，让我睡得更好！

**天气控制器停止**:
- 这个是空调省电程序。
- 在工作日上午的10点会把空调调高到28度，在10点半会直接关掉空调，防止早上出门忘记关空调浪费电。此外，假如「初升的东曦」没有叫醒我的话，也会因为没有空调被热醒了，相当于多1层保险！

**报警系列**:
- 这个是全方位的家庭环境与服务健康监控报警系统。
- 触发条件是花草缺水或缺肥、冰箱温度异常时(说明门没关好)、空气中VOC浓度超标、网络断开、电脑48小时没有开启过，都会第1时间发送推送通知到手机，随时掌握家里的所有状况！

**叫鱼起床**:
- 这个是鱼缸灯光控制程序。
- 因为我的鱼缸也是智能的，所以帮鱼也调整1下生物钟，让鱼更健康1些！和「究极太阳常亮」1样会平滑调节鱼缸灯的亮度，模拟河里的光照变化！

其他的大家就到`automations`文件夹里面自己看吧！
