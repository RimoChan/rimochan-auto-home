# 莉沫酱家里！

大家有用过智能家居吗？

前1段时间我也买了1套智能家居，空调、灯、插线板、窗帘之类的，什么都有。

结果买回来之后，发现这些「智能」产品大多不是很智能，没有蟾蜍先生的1半聪明！

于是我就在家部署了home assistant服务，它可以控制智能家居，相当于是家的管理中心，我可以在上面配置自动化，让智能家居变得聪明1些。

所以这个仓库就是放我在home assistant上写的自动化文件，这样大家以后买了智能家居，可以把它们抄回去，就不会觉得智能家居那么难用了！


## 使用方法

在home assistant的「自动化与场景」页面创建1个新的自动化，然后在右上角进入「以YAML编辑」，把你想要的yaml粘贴进去就可以了。

不过仓库里的配置文件中device_id字段被替换成了占位符，你要记得把它们改成你的device_id！


## 介绍1些自动化

**究极太阳常亮**: 
- 这个是控制房间亮度的程序。
- 我把家里的灯泡都换成了智能灯泡，然后它就可以根据时间调整亮度和色温，比如在中午更亮1些，在晚上就逐渐变暗。这样可以预防现代人由于室内生活生物钟混乱引起的失眠之类的问题！

**初升的东曦**: 
- 这个是替代闹钟的程序。
- 它会在快到早上10点的时候把床头灯的亮度从0逐渐提升到100，模拟太阳升起来把人叫醒的感觉，这样就不会被闹钟吓到了。还有就是闹钟是广播1个变化，不是广播1个状态，用闹钟的时候经常早上醒来，很害怕，要看1下时间才知道是不是错过了闹钟。用初升的东曦就没有这个问题，只要房间是暗的就说明还能睡！

**魔雾雨**: 
- 这个是控制加湿器的程序。
- 现在有很多自称智能的设备，比如智能加湿器可以根据环境湿度自动调整档位，但实际上它们的传感器是在机器身上的，然后它自己喷自己，测出的环境湿度值根本不准。所以用这个程序来轮询房间里的湿度计的湿度，决定是否调整档位，这样1来房间就可以真正地恒定湿度了！

其他的大家就到`automations`文件夹里面自己看吧！
